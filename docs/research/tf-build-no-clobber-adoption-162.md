# Cross-consumer no-clobber publication and Agora preflight (CATSS #162)

## Evidence and scope (2026-11-17, before tests/production)

The original `tf-build` charter is consolidation of repeated Text-Fabric converter infrastructure, verified through actual production call sites and installed-artifact checks. ORAEC-TF, IIP-TF and CopticScriptorium-TF have now merged real integration. CATSS-TF is a distinct Python >=3.11 converter with a runnable synthetic standalone corpus and parent TF projections.

**Verified filesystem defect:** `materialize_corpus`, `materialize_bhsa` and `materialize_lxx` each reject `destination.exists()` before expensive parsing, then the three sibling `_publish_bundle` routines allocate a temporary directory under the destination's parent, write TF/TSV, and call `temp_path.replace(destination)`. On POSIX, replacement of an **existing empty directory** succeeds. A local Python filesystem probe confirmed `a.replace(b)` replaced a competing existing empty `b` and changed its inode. A dangling destination symlink also incorrectly passes `exists()` and can be replaced. The early check must remain useful but cannot ensure atomic nonreplacement.

**Released shared contract:** inspected actual immutable `alexsosn/tf-build@v0.1.0rc1` source. Public `tf_build.publication.publish_path_no_clobber(source, destination)` re-exports the low-level primitive, implemented on Linux as `renameat2(RENAME_NOREPLACE)`, macOS `renamex_np(RENAME_EXCL)`, Windows `os.rename`; it refuses existing destinations and fails closed on unsupported systems. The helper **does not** stage/write/validate/clean up. CATSS retains its own temp staging and exception cleanup. `tf_build.agora.prepare_agora_output(root)` verifies existing non-symlink empty host-owned staging, raises `AgoraOutputError(ValueError)`, and does not modify it. `catss_tf.agora_adapter._check_inputs` duplicates this while additionally verifying CATSS local source is a real directory and rejects source/output ancestry overlap. Preserve all CATSS-specific checks and live output hardlink rollbacks.

**Published distribution:** `tf-build==0.1.0rc1` is available as a GitHub Release wheel, with verified SHA256 `dff2a14c0299422b4716217d04e6d43b47e714f4dacdb21d9939292051e82c9a`, **not established on PyPI**. Its wheel requires Python >=3.11 and Text-Fabric >=13.1,<14. CATSS-TF supports Python >=3.11 and already declares `text-fabric[github]>=13.1,<14` in its `tf` and `dev` extras. Adding a required direct URL to the shared wheel is a deliberate install-weight tradeoff: base `catss-tf` will now install Text-Fabric, while existing **source-only CLI commands still work** and canonical/BHSA/LXX public materializers gain immediate safe publication without changing the already-available base API contract. The `tf` extra remains useful specifically for Text-Fabric's **GitHub backend**. Installation of the immutable release requires first-install network access, but source conversion itself remains offline. CATSS currently uses setuptools, which accepts PEP 508 direct references. Its already-published `0.1.0` wheel is immutable and not retroactively modified. **Keep tf-build imports lazy inside publication/Agora input functions**, so the existing intentional `pip install --no-deps dist/*.whl` command-line root-import smoke remains possible; normal project installs acquire dependencies.

**Existing acceptance evidence:** `tests/test_canonical_materializer.py` exercises real synthetic CATSS alignments with plus/minus/retroversion, stable IDs, native `tf.fabric.Fabric.loadAll`, byte-deterministic TF and TSV, and failure no-partial-output. `tests/test_agora_adapter.py` uses real tiny source/host directory to reload Text-Fabric and tests missing/symlink/occupied roots, source path overlap, forged native artifacts, hardlink competing destination, and rollback. BHSA and LXX materializer test suites exercise real TF parent projections. Existing `.github/workflows/ci.yml` includes Python 3.11–3.13 Ruff, strict mypy, pytest, a synthetic release/wheel install smoke and a separate source-audit gate. CATSS data/BHSA/LXX raw corpora are never to be committed or mirrored.
