# #141 — inspect genuinely unresolved translation-technique evidence

## Research — current code and pinned real CATSS

The canonical writer already catches `TechniqueError` and places `catss_tt_status=unclassified` and the exception's **verbatim** `catss_tt_unclassified_reason` on an alignment slot. The same slot carries `catss_alignment_id`, `catss_source`, `book/chapter/verse`, `catss_line_first`/`last`, and `catss_mt_n`/`catss_lxx_n`. Lexical MT-A and LXX tokens and typed annotations own that slot through `oslots`. No new graph model or source transformation is required.

Full 46-file CI after merged #135 and #140 pins **102 unclassified** translation-technique slots. Of the 71 newly unclassified Sirach alignments after the MT witness-number fix, source-level before/after comparison shows 43 Hebrew-empty/Greek-present, 28 `CATSS LXX-minus` with no surviving MT lexical item. One additional Sirach witness lacuna remained unclassified both before and after. This is a conservative unresolved status, **not** evidence for a real Greek plus, Greek minus with MT word, or a word-level manuscript attestation. #136 handles philological classification, #132 manuscript readings.
