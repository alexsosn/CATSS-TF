## Grounded evidence from the actual parser, public API and real corpus

- `src/catss_tf/query.py::find_unclassified_alignments(api, source=None, reason_contains=None)` returns typed `UnclassifiedAlignment` results from the **standalone** `alignment`-slot TF warp only. Each hit includes stable `catss_alignment_id`, source filename, source book/chapter/verse, physical `catss_line_first/last`, original exact `catss_tt_unclassified_reason`, MT/Greek lexical counts, source-ordered elements and typed annotations. It refuses wrong warp and a partially loaded TF without `catss_tt_status`; a source with only derived states legitimately returns an empty result.
- `tests/test_unclassified_query.py` already proves a tiny, licensed-safe synthetic 2-source fixture with **2** intentionally unclassified Sirach rows, one Hebrew-empty Greek `QEOS` case and one raw Greek `---` minus case lacking MT lexical material; it independently compares returned stable IDs and original reasons to a complete native `F.otype.s("alignment")` scan. Reason filters `reason_contains="Hebrew-empty"` and `"LXX-minus"` each return one, and Genesis source returns zero. The two unclassified Sirach source physical lines are **3** and **4**. Same verse/nearby manuscript `7` markup is not evidence that a specific Hebrew manuscript attests a lexical reading.
- Full 46-file CI previously verified exactly **102** unclassified alignments by independently parsing each source and rederiving technique errors, including at least 71 newly unclassified Sirach marker-only lines. This is a **real-source independent oracle**, separate from a tiny standalone demo. It cannot be exported as licensed CATSS text or promoted into a corpus-wide negative hypothesis.
- The current `docs/researcher-cookbook.md` mentions `find_unclassified_alignments` but lacks a runnable, newcomer-oriented complete example that can generate a native TF corpus, print reason/provenance fields and check the distinction between unclassified and inferred translation additions/omissions.
