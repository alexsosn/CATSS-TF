# No-clobber parent module publication, CATSS #166

## Research before behavior/test changes (2026-11-17)

The merged canonical CATSS fix #162/#163 imports the published `tf_build.publication.publish_path_no_clobber` and successfully uses it in `canonical_materializer._publish_bundle`. It also pins the immutable GitHub Release `tf-build v0.1.0rc1` wheel via SHA256 to CATSS runtime metadata. **Do not redo** any of that work, or Agora preflight, in this issue. Its exact-head CI/review/merge were recorded in #163. Superseded draft #164 was closed after identifying this concurrent main change.

Actual current `main` code still has two copies of the old final publish statement: `bhsa_materializer._publish_bundle` and `lxx_materializer._publish_bundle` stage their own TF module/TSV files in a private sibling directory and then call `temp_path.replace(destination)`. Public `materialize_bhsa` and `materialize_lxx` check `destination.exists()` earlier, before expensive parsing and parent verification. The gap allows a competing **empty destination directory** to be replaced silently on Linux/POSIX after initial preflight. Local native POSIX probe confirmed this behavior. The already merged canonical fix uses Linux `renameat2(RENAME_NOREPLACE)`, Darwin `renamex_np(RENAME_EXCL)` and Windows nonreplacement `os.rename` through public tf-build. The exact shared tagged helper refuses existing claimed targets without changing them, and the native writer's exception handler already removes the private staged directory on any failure.

The superseded draft #164 ran **actual** test-only RED CI on unchanged sibling production blobs at commit `2868269013a47565e5eed90af13f6b349ffc3e9c`: Python 3.12 test suite had two sibling tests `Failed: DID NOT RAISE FileExistsError` while the old `Path.replace()` silently overwrote a freshly claimed empty directory. Its other four failures concerned already-merged canonical/Agora/packaging scope and must **not** be reused as evidence of new bugs. For this ticket we need a fresh tests-only head from current `main` (now with #163 merged), then an independent final CI and review.
